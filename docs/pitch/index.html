The problem

Students don’t fail at coding first — they fail at specifying.

Vague briefs

“NLP + cybersecurity, five weeks, no idea…” becomes unstructured chat that evaporates.

Pivots and creep

React becomes Flutter. Facial recognition sneaks into a phishing detector. Nothing tracks breakage.

Prompt dumping

Whole transcripts pasted into Cursor. Agents get filler, contradictions, missing acceptance criteria.

No adversarial check

Friendly chatbots agree. Feasibility, datasets, and AI necessity never get grilled.

Insight

The structured project specification is the product. The Cursor prompt is a compiled export.

If conversation is the source of truth, every agent run inherits chaos. If ProjectState is the source of truth, every prompt is measurable, coverable, and repairable.

Product philosophy

Eight non-negotiables

1. One workspace

Capabilities, not mandatory tabs.

2. ProjectState wins

Conversation is input, never authority.

3. Compile from state

Never dump raw chat into the final prompt.

4. Research on demand

Provenance; no invented papers or URLs.

5. Grill is adversarial

Weaknesses and must-resolve questions — no vanity score.

6. Provenance

USER / RESEARCH / AI_RECOMMENDATION / SYSTEM_DEFAULT / INFERRED.

7. Hybrid NLP

Rules and embeddings where measurable; LLM where generative.

8. Do not over-engineer

One app, clear services, justified models.
